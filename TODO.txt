Deliverable III: Work Plan
F26-066 · Mixture of Experts Framework for Domain Adaptive Colorization
Pipeline to build
•	Decomposition: Grounded-SAM with domain text prompts, returning a mask, label, box and score per region
•	Routing: label-to-domain table, overlap rule, fallback for uncovered pixels
•	Extraction: crop with a configurable context margin, clamp to the image, resize, map back
•	Colorization wrapper: four expert slots, all loading the same pretrained DDColor-T, ab output only
•	Blending: soft masks, weighted ab combination, original L preserved, switches for binary paste and for boxes instead of masks
•	Config file: margin, smoothing width, blending on/off, region shape, detection thresholds
•	Metric code: mIoU, pixel coverage, routing accuracy and confusion matrix, FID, LPIPS, colorfulness, PSNR, SSIM, Lab ΔE, boundary ΔE
•	Test sets: fixed image-ID lists for the domain, region-crop, segmentation and mixed-scene sets
•	Unit tests for each component
Experiments to run
•	E1, decomposition quality: mIoU, pixel coverage and fallback usage on a COCO-Stuff subset, with a detection-threshold sweep
•	E2, routing accuracy: accuracy and confusion matrix against domain labels derived from COCO-Stuff categories
•	E3, baselines: pretrained DDColor-T and DDColor-L on whole images, on the domain and mixed-scene sets
•	E4, pipeline control: the full pipeline with identical experts compared with E3, changing one component at a time: blending on/off, smoothing width, margin of 0, 0.1, 0.2 and 0.3, masks versus boxes
